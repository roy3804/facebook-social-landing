# דף נחיתה Gmail — עיצוב חדש ב־Next.js

פרויקט Next.js App Router ו־TypeScript, המבוסס על הפרויקט המקורי שהועלה.
העיצוב עודכן עם המחשה של Gmail Inbox, אייקוני Gmail ורקעים בארבעה צבעים: כחול, צהוב, ירוק ואדום.

## הפעלה במחשב

נדרש Node.js 22, בהתאם להגדרה המקורית בפרויקט.
חלצו את ה־ZIP לתיקייה חדשה ופתחו מסוף בתיקייה שמכילה את `package.json`.

```bash
npm ci
npm run dev -- -p 3302
```

פותחים בדפדפן:

```text
http://localhost:3302
```

כאשר כבר רץ פרויקט אחר באותו פורט, עוצרים אותו ב־Ctrl+C לפני ההפעלה.
אפשר גם להריץ בפורט אחר, לדוגמה `npm run dev -- -p 3303`.

## בדיקת קוד ובניית גרסת production

```bash
npm run typecheck
npm run build
npm run start -- -p 3302
```

לא נוספו ספריות UI או אנימציה. גרסאות Next.js, React ו־TypeScript נשמרו מהפרויקט המקורי.
`package-lock.json` נשמר תואם; רק שם הפרויקט ומספר גרסת הפרויקט עודכנו.

## מה השתנה

- איור הטלפון הוחלף ברכיב `GmailInbox` — חלון Gmail עם הודעות לדוגמה, כרטיסיות דואר ואייקון Gmail מרחף. זו המחשה הנבנית ב־HTML/SVG/CSS, לא תמונה של עמוד שלם ולא התחברות לחשבון.
- רקע ראשי בגווני כחול, צהוב, ירוק ואדום, כותרת צבעונית, צללים וריווח מעודכנים.
- אזור ניווט, כרטיסי מידע, שלבי פנייה, שאלות נפוצות, אזור יצירת קשר ופופ־אפ תואם.
- תצוגות נפרדות למחשב ולנייד, תמיכה בעברית וב־RTL, ופונטים Rubik ו־Heebo דרך `next/font`.
- אייקון SVG מעודכן ללשונית הדפדפן.
- נשמרו מספר הוואטסאפ, נוסח ההודעה והגדרת הפופ־אפ אחרי 6 שניות.
- נוספה לפופ־אפ האפשרות „אמשיך לקרוא בינתיים”, יחד עם סגירה ב־X, ב־Escape ובאזור שמסביב לחלון, והחזרת מיקוד מקלדת.
- תמונות הטלפון הישנות הוסרו מהעותק המעודכן. הקובץ המקורי שהועלה אינו משתנה.

## קבצים לעריכה

| קובץ | תפקיד |
| --- | --- |
| `app/page.tsx` | טקסטים, סדר האזורים ותוכן השאלות |
| `app/globals.css` | עיצוב, צבעים, גודל רכיבים והתאמה למסכים |
| `components/GmailInbox.tsx` | ההמחשה של תיבת Gmail |
| `components/Icons.tsx` | אייקוני Gmail, וואטסאפ ושאר האייקונים |
| `components/OfferPopup.tsx` | תוכן הפופ־אפ |
| `lib/popup.ts` | פתיחה, סגירה, השהיה, נגישות וזכירת הצגה |
| `lib/site.ts` | מספר הוואטסאפ, הודעת הפתיחה והגדרות הפופ־אפ |
| `app/layout.tsx` | פונטים, שפה, כיווניות ו־metadata |
| `app/icon.svg` | אייקון לשונית הדפדפן |

לכיבוי ההצגה האוטומטית, משנים את `popupEnabled` ל־`false` ב־`lib/site.ts`.
כפתור „פתיחת חלון ההצעה” ממשיך לעבוד גם כשההצגה האוטומטית כבויה.
החלון נשמר כמוצג בלשונית הנוכחית כאשר `sessionStorage` זמין.

הגדרת `robots` המקורית היא `noindex, nofollow`. היא לא שונתה בעדכון העיצוב.

## הפרדה מ־Google

העמוד מציג המחשה בלבד. אין חיבור ל־Gmail API, אין מסך התחברות ואין איסוף סיסמאות או קודי אימות.
נשמרו ההסברים לגבי מהות הפנייה והודעת העצמאות של העמוד. הסמלים נועדו לזיהוי השירות, לא להצגת חסות או אישור.
אין ניווט אוטומטי לוואטסאפ ואין שליחה אוטומטית של הודעות.

## בדיקות ומגבלות הסביבה

בוצעו בדיקות תחביר TS/TSX ו־CSS, וכן בדיקות תצוגה והתנהגות בדפדפן Chromium על HTML שהופק מרכיבי הפרויקט, עם ה־CSS וקוד הפופ־אפ של הפרויקט.
נבדקו רוחבי מסך מ־320 ועד 1920 פיקסלים, כפתורי סגירה, מקלדת, שאלות נפוצות, קישורים והפופ־אפ.

**לא בוצע build מלא של Next.js ולא בוצע typecheck מלא מול חבילות Next/React.**
סביבת העבודה לא הצליחה לגשת ל־npm כדי להוריד את התלויות. בדיקת התצוגה אינה בדיקת hydration של React.
הבדיקה החזותית השתמשה בפונט עברי חלופי המותקן בסביבת הבדיקה; הפרויקט עצמו משתמש ב־Rubik וב־Heebo כפי שהוגדרו במקור. נדרש חיבור אינטרנט להורדת הפונטים בשלב הבנייה.

פירוט הבדיקות נמצא ב־`CHECKS.md`. לא בוצעה פריסה ל־Vercel ולא נעשה שינוי אוטומטי במחשב שלכם.
